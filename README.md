# comma

project management tool

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Screens

- `#/` – projects home. Hovering (or keyboard-focusing) a project card expands it into its details.
- `#/project/system-design` – the System Design project dashboard (opened by clicking that card; the logo leads back).

## Fonts

The UI uses **Garet** (Book, Heavy) and **Gilroy** (Regular, Medium). They live in `public/fonts/` as `.woff2` files and are loaded from `src/index.css`.

## Live site

Every push to `main` deploys to https://manasiii20.github.io/comma/
